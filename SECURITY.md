# Security policy

*Italiano sotto.*

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Use
[private vulnerability reporting](https://github.com/Samuel782/Duetto/security/advisories/new) on GitHub.
Include the Duetto version, your operating system, what can happen and how to reproduce it.
Never include API keys, passwords or real event transcripts.

The report is read by the maintainer, who will confirm receipt, assess it and tell you when a fix is released.
Please allow time for a fix before publishing the details.

## Supported versions

Security fixes are released for the **latest published version** only. Updating is the way to receive them:
Duetto tells you at startup when a newer version is available, unless you turned that off.

## Segnalare una vulnerabilità

**Non aprire una issue pubblica** per un problema di sicurezza: usa la
[segnalazione privata](https://github.com/Samuel782/Duetto/security/advisories/new) di GitHub.
Indica versione di Duetto, sistema operativo, cosa può succedere e come riprodurlo.
Non includere chiavi, password o trascrizioni di eventi reali.
Le correzioni escono solo per l'ultima versione pubblicata.
